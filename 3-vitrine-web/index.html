DoraHacks Build #5120

Cheer Tec Protocol

Sovereign multi-tenant B2B SaaS infrastructure for multi-level commerce.

Cheer Tec connects physical point-of-sale terminals and self-service kiosks (Point Zero) directly to a deterministic on-chain execution engine, eliminating operational silos and automating real-time revenue splitting.

Domain 1: Kernel OS

Rust / Anchor smart contracts managing tenant isolation via PDA and sub-400ms atomic pay-splitting across management, master franchises, and units.

Domain 2: Point Zero (POS Edge)

Tactile checkout terminals handling basket validation, VAT computation, inventory de-crementation, and offline-first asynchronous synchronization.
