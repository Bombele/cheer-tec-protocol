# Cheer Tec Protocol

Sovereign multi-tenant B2B SaaS protocol automating POS transactions, atomic Pay-Splitter (<400ms), DePIN supply chain, and live accounting on Rust/Anchor.

- **Domain 1 (`1-kernel-os/`)**: Core execution engine, Anchor smart contracts, domain bridges, and real-time financial routing.
- **Domain 2 (`2-pos-edge/`)**: Point Zero tactile interface, self-service kiosks, and offline-first resilience.
